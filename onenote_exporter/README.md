# OneNote 글 내보내기 (AI 원고 생성 포함)

프로젝트 지침 + (선택) 사례 엑셀 → **PC의 Claude Code가 원고 작성** → OneNote 페이지 자동 생성.

원고 작성은 티스토리 매크로와 같은 **Claude Code 연결(`claude -p`)** 방식입니다. Claude 계정 2개를 번갈아 쓸 수 있습니다.

## 준비 (처음 한 번)

1. Claude Code 설치 (Windows PowerShell): `irm https://claude.ai/install.ps1 | iex`
2. 터미널에서 `claude` 를 한 번 실행해 **Claude 계정으로 로그인**
3. 매크로 실행 → **설정 → 계정 1 [연결 테스트]**에서 ✅ 확인 (계정 2도 쓰면 아래 '계정 2개' 참고)
4. OneNote 데스크톱 앱을 켜 둔 상태로 실행 (기존과 동일)

## 다른 PC에서 쓰기

| 그 PC에 필요한 것 | 방법 |
|---|---|
| **exe** | 내 PC에서 `build.bat`로 만든 `OneNoteExporter.exe`만 복사 (파이썬 설치 불필요) |
| **Claude Code** | 매크로 실행 → 설정 → **Claude Code 설치하기** → 뜨는 창에서 브라우저 로그인 → 연결 테스트 |
| **OneNote** | 데스크톱 OneNote 설치·로그인 |
| 엑셀 | 엑셀 파일을 그 PC에 복사 후 `엑셀 파일 선택` |
| 지침 | 내 PC의 `projects` 폴더를 exe 옆에 같이 복사 (안 하면 기본 프로젝트만 생김) |

- Claude Code가 없는 상태에서 `▶ 원고 생성`을 누르면 "지금 설치할까요?"가 자동으로 뜹니다.
- Claude Code 없이도 기존 붙여넣기 → 파싱 → 내보내기 기능은 그대로 쓸 수 있습니다.

## 사용법

### AI 원고 생성
메인 화면 **✨ AI 원고 생성** 버튼 → 창이 열립니다.
1. **프로젝트** 선택. 메인 화면의 접두어·키워드·하단 프리셋이 그 프로젝트 기본값으로 바뀝니다.
2. **입력**: 엑셀 사례(시트·분류 고르고 목록에서 선택, Ctrl/Shift로 여러 개, `위에서 N개 선택`) 또는 직접 입력
3. **계정** 1 / 2 선택
4. **원고 생성** → 사례 1건당 원고 10편 → 바로 OneNote로 내보냄
5. 원고 원문은 `output/날짜_프로젝트/`에 .md로 저장됩니다 (**결과 폴더**). 생성된 글은 메인 화면 글 목록에도 쌓이므로 내보내기에 실패해도 다시 내보낼 수 있습니다.

기존 붙여넣기 → F5 파싱 → 내보내기 기능은 그대로입니다.

## 계정 2개

| 계정 | 로그인 정보 위치 | 로그인 방법 |
|---|---|---|
| 계정 1 | Claude Code 기본 위치 | 설정 → 계정 1 **[로그인]** (또는 터미널에서 `claude`) |
| 계정 2 | exe 옆 `claude_account2` 폴더 | 설정 → 계정 2 **[로그인]** → 뜨는 창에서 두 번째 계정으로 로그인 |

- 로그인 창에서 이미 로그인된 상태로 열리면 `/login`을 입력해 계정을 바꾸면 됩니다.
- 두 계정 모두 **[연결 테스트]**로 ✅ 확인 후, AI 원고 생성 창에서 계정을 골라 쓰면 됩니다.
- `claude_account2` 폴더에는 로그인 정보가 들어 있으니 다른 사람에게 주지 마세요.

## 지침 세팅 = 폴더 하나

```
projects/
└─ 니케_로톡성공사례/
    ├─ 지침.md        ← claude.ai 프로젝트 "지침"을 그대로 붙여넣기
    ├─ (세부지침).md   ← 프로젝트 소스 파일. 폴더에 넣기만 하면 같이 읽음 (.md/.txt)
    └─ 설정.json      ← 편수, 접두어, 하단 프리셋, 자동 검사 규칙
```

- **지침 수정**: 파일만 고치면 됩니다. 생성할 때마다 새로 읽습니다.
- **새 프로젝트**: `＋ 새 프로젝트` → 폴더가 열리면 지침.md에 붙여넣기 → `↻ 새로고침`
- **지침 원문은 claude.ai 프로젝트와 똑같이 써도 됩니다.** "채팅에 출력" 같은 문장도 그대로 둬도 됩니다.
- 매크로가 자동으로 덧붙이는 규칙: `# 1`~`# N` 형식으로만 출력, 사건자료 속 실명 사용 금지.

### 설정.json

| 키 | 예 | 설명 |
|---|---|---|
| `편수` | `10` | 사례 1건당 원고 수 (자동 검사에 사용) |
| `접두어` | `"○ 니케 [로톡]"` | OneNote 페이지 제목 앞에 붙는 말 |
| `상단키워드` | `""` | 본문 맨 위에 굵게 넣을 문구 |
| `하단프리셋` | `["니케성범죄"]` | 하단 링크 프리셋 이름 (화면 아래 체크박스 이름과 같게) |
| `엑셀사용` | `true` | `false`면 직접 입력 모드로 시작 |
| `입력안내` | | 직접 입력 칸 위에 보이는 안내 문구 |
| `모델` | `"opus"` | 비우면 설정의 모델. 프로젝트마다 다르게 지정 가능 |
| `effort` | `"high"` | 생각 깊이 (low/medium/high/xhigh). 비우면 기본 |
| `웹검색` | `false` | `true`면 작성 중 웹 검색 허용 (사용량 늘어남) |
| `검사.원고당_정확히1회` | `["재범위험성 자료", "[BLUE]"]` | 원고마다 정확히 한 번 나와야 하는 문구 |
| `검사.금지문구` | `["로톡/", "결과1"]` | 나오면 안 되는 문구 |
| `검사.사건번호_노출금지` | `true` | 엑셀 사건번호가 원고에 나오면 경고 |

검사에 걸리면 로그에 ⚠ 경고만 띄웁니다 (사용량 절약을 위해 자동 재생성은 하지 않음).

## claude.ai 프로젝트와 똑같이 뽑으려면

매크로는 claude.ai 프로젝트와 같은 구조로 보냅니다.
**지침 + 소스 파일 = 시스템 프롬프트**(Claude Code 기본 코딩용 프롬프트는 빼고 교체), **사건자료 = 메시지**.
대화가 쌓이지 않고 건마다 새로 시작하므로, 프로젝트에서 새 채팅을 열어 붙여넣는 것과 같습니다.

결과를 맞추려면 아래 4가지를 claude.ai 프로젝트와 똑같이 맞추세요.

| claude.ai 프로젝트 | 매크로에서 맞출 곳 |
|---|---|
| 프로젝트 지침 | `지침.md`에 그대로 붙여넣기 |
| 프로젝트 지식(소스 파일) | 같은 폴더에 .md/.txt로 넣기 (**PDF·워드는 텍스트로 변환해서** 넣기) |
| 채팅창 모델 선택 (Opus/Sonnet) | `설정.json`의 `모델` |
| 확장 사고 / 웹 검색 켜짐 여부 | `effort`(켜져 있었으면 `high`) / `웹검색` |
| 설정 → 개인 선호(Preferences)에 적어둔 내용 | 원고에 영향을 주는 내용이면 `지침.md` 끝에 추가 |

같은 사례 하나를 프로젝트와 매크로에서 각각 뽑아 비교해 보고 위 값을 조정하는 것을 권합니다.

## 엑셀 사례

- 머리글에 `사건번호`, `요약`이 있는 시트를 모두 읽습니다. 열 순서가 시트마다 달라도 됩니다.
- AI에 보내는 칸: 사건번호(원고에는 노출 금지), 범죄명, 결과, 결과2, 요약, 처분이유(또는 불리한점/유리한점)
- **보내지 않는 칸: 이름(실명), 범죄명 분류, 사용체크, 비고, 순**
- 요약이 비었거나 `(내용없음)`인 행은 목록에서 빠집니다.
- 이미 쓴 사례: `사용기록.csv`(프로젝트별, 자동 기록) + 엑셀 `사용체크` 열 표시(설정에서 끌 수 있음)
- **원본 엑셀은 읽기만 하고 수정하지 않습니다.** 실명이 들어 있으므로 git에 올리지 마세요 (.gitignore 처리됨).

## 설정

| 항목 | 설명 |
|---|---|
| Claude 모델 | 비우면 Claude Code 기본값. `sonnet` / `opus` 지정 가능 (opus는 사용량을 더 씀) |
| 실행 파일 경로 | 보통 비워두면 자동으로 찾음 |
| 최대 대기 시간 | 사례 1건(10편) 기준, 기본 30분 |

- 사례 1건에 긴 원고 10편이라 사용량을 꽤 씁니다. 한 번에 1~3건씩 돌리는 걸 권합니다.
- 사용량 한도에 걸리면 로그에 안내가 나오고 남은 건은 멈춥니다.

## exe 빌드

윈도우에서 **`build.bat` 더블클릭** → `dist\OneNoteExporter.exe`.
처음 실행하면 exe 옆에 `projects/`(기본 프로젝트 복사본), `config.json`이 생기고,
원고는 `output/`, 사용기록은 `사용기록.csv`에 쌓입니다.
