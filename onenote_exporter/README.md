# OneNote 글 내보내기 (AI 원고 생성 포함)

프로젝트 지침 + (선택) 사례 엑셀 → **PC의 Claude Code가 원고 작성** → OneNote 페이지 자동 생성.

원고 작성은 티스토리 매크로와 같은 **Claude Code 연결(`claude -p`)** 방식입니다. Claude 계정 2개를 번갈아 쓸 수 있습니다.

## 준비 (처음 한 번)

1. Claude Code 설치 (Windows PowerShell): `irm https://claude.ai/install.ps1 | iex`
2. 터미널에서 `claude` 를 한 번 실행해 **Claude 계정으로 로그인**
3. 매크로 실행 → **✨ AI 원고 생성** 창의 계정 줄에서 `● 로그인됨`(초록) 확인. 빨간색이면 옆 **[로그인]**
4. OneNote 데스크톱 앱을 켜 둔 상태로 실행 (기존과 동일)

## 다른 PC에서 쓰기

| 그 PC에 필요한 것 | 방법 |
|---|---|
| **exe** | 내 PC에서 `build.bat`로 만든 `OneNoteExporter.exe`만 복사 (파이썬 설치 불필요) |
| **Claude Code** | 매크로 실행 → 설정 → **Claude Code 설치하기** → 뜨는 창에서 브라우저 로그인 → AI 원고 생성 창에서 로그인 상태 확인 |
| **OneNote** | 데스크톱 OneNote 설치·로그인 |
| 엑셀 | 엑셀 파일을 그 PC에 복사 후 `엑셀 파일 선택` |
| 지침 | 내 PC의 `projects` 폴더를 exe 옆에 같이 복사 (안 하면 기본 프로젝트만 생김) |

- Claude Code가 없는 상태에서 `▶ 원고 생성`을 누르면 "지금 설치할까요?"가 자동으로 뜹니다.
- Claude Code 없이도 기존 붙여넣기 → 파싱 → 내보내기 기능은 그대로 쓸 수 있습니다.

## 사용법

### AI 원고 생성
메인 화면 **✨ AI 원고 생성** 버튼 → 창 하나에서 전부 합니다. **모든 설정은 프로젝트별로 자동 저장**되어 다음에 그 프로젝트를 고르면 그대로 나옵니다 (설정 파일을 직접 고칠 필요 없음).
1. **프로젝트** 선택 → 그 프로젝트에서 마지막으로 쓴 설정이 자동으로 채워집니다 (섹션 포함).
2. **사례당 편수**, **계정**(1 / 2 / 1 + 2 동시). 계정 옆에 로그인 상태와 사용량(5시간·7일 %)이 보입니다.
3. **OneNote**: 섹션, 접두어, 키워드, 하단 구분선, 하단 문구
4. **입력**: 엑셀 사례(체크 또는 `위에서 N개 선택`) 또는 직접 입력
5. **원고 생성** → 계정별 진행 막대 (`원고 6/10편 작성 중 · 5,580자 · 3분 12초`)
6. 원고 원문은 `output/날짜_프로젝트/`에 .md로 저장 (**결과 폴더**). 생성된 글은 메인 화면 글 목록에도 쌓입니다.

진행 상황 위의 두 옵션 (기본 켜짐):
- **검사에 걸린 원고는 그 편만 자동으로 다시 쓰기**: 예) `[BLUE]`가 빠진 # 2만 다시 써서 OneNote에 넣습니다. 10편을 통째로 다시 쓰지 않아 사용량이 적게 듭니다.
- **한도에 걸리면 기다렸다 이어 쓰기**: 사용량 한도에 걸리면 Claude Code가 알려주는 초기화 시각(+1분)까지 기다렸다가 남은 사례를 이어서 씁니다. 12시간 넘게 기다려야 하면(7일 한도 등) 그 계정은 멈춥니다. `1 + 2 동시`면 한 계정이 기다리는 동안 다른 계정이 계속 씁니다.

### 원고가 덜 왔을 때 (예: 10편 중 7편)
- 빠진 번호(#8~#10)만 **자동으로 이어서** 씁니다. 10편을 다시 쓰지 않으므로 사용량이 적게 듭니다.
- 사용량 한도로 중간에 끊기면, 끊기기 전까지 **다 쓴 원고는 보관**하고 한도가 풀린 뒤 나머지만 씁니다.

### 작업 기록(로그) 파일
- `logs/날짜.log`에 모든 진행 상황이 남습니다 (AI 원고 생성 창 **[기록(로그)]** 버튼). 밤에 돌린 결과를 아침에 확인할 때 보세요.
- 원고가 덜 왔으면 `○편만 받음 (종료 이유, 출력 토큰) → ○번만 이어서 씁니다`처럼 기록됩니다.
- 원고 원문은 `output/날짜_지침이름/`에 사례별 .md로 저장됩니다.

### 로톡에 붙여넣기 (대제목·소제목)
- 원고의 `##` 소제목은 **대제목**, `###`는 **소제목**으로 OneNote에 '제목 스타일'로 들어갑니다 (하단 문구는 제목이 아닌 굵은 글씨).
- OneNote에서 복사 → 로톡에 붙여넣기. (기존 로톡 변환기도 그대로 쓸 수 있음)
- 기존 로톡 변환기도 그대로 쓸 수 있습니다 (글자 크기 기준 18pt/14pt 유지).

### 로톡 링크 기록 (엑셀 + OneNote, 한 번에)
메인 화면 **🔗 링크 기록** → 섹션 고르기 → 링크 붙여넣기 → **저장**
- OneNote 섹션의 페이지를 **직접 읽어 옵니다** (매크로를 껐다 켜도, 예전 페이지도 언제든). 목록 순서 = OneNote 페이지 순서.
- **숨길 제목**: 이 글자로 시작하는 제목은 목록에서 안 보입니다. 기본 `사용` → 이미 `ㅡ`가 지워져 "사용 …"으로 시작하는 (올린) 페이지는 숨김. 쉼표로 여러 개, 비우면 전부 보임.
- **기록 엑셀**: **[바꾸기]**로 기존 엑셀(예: 로톡 url 엑셀)을 고르면 **맨 아래에 이어서** 추가합니다. 기존 서식·링크·열 너비는 그대로 두고, 새 줄은 윗줄과 같은 서식으로 붙습니다 (한셀에서 만든 파일도 가능).
- 형식: `날짜 | 아이디 | 사건번호 | 제목([부터) | url`. **날짜는 OneNote 제목에 적힌 날짜** (예: `ㅡ 사용 11/25 수 로톡 …` → `11/25 수`, 요일이 없으면 자동으로 붙임, 제목에 날짜가 없으면 '날짜 없는 글에 넣을 날짜'). url은 눌러서 열리는 링크. 머리글 줄에 **필터(정렬) 버튼**이 켜져서 날짜·아이디 순으로 정렬할 수 있습니다.
- 저장하면 한 번에: ① 엑셀 기록 ② OneNote 페이지 맨 위에 `로톡 링크: 주소` ③ **OneNote 제목 정리** (끌 수 있음)
  - 제목 앞의 `ㅡ` 삭제: `ㅡ 사용 11/25 수 로톡 […] …` → `사용 11/25 수 로톡 […] …`
  - 제목에 날짜가 없으면 **날짜 없는 글에 넣을 날짜**(예: `11/25`, 요일 자동)로 `사용 날짜 로톡`을 붙임: `ㅡ 로톡 [강제추행변호사 성공사례] …` → `사용 11/25 수 로톡 [강제추행변호사 성공사례] …`
  - 엑셀 날짜 칸도 같은 날짜로 들어갑니다.
- 같은 url은 엑셀에 두 번 들어가지 않습니다. 아이디·숨길 제목·옵션·엑셀 위치는 자동으로 기억합니다.
- 기록 엑셀이 엑셀/한셀에서 열려 있으면 저장이 안 되니 닫고 저장하세요.
- Q&A의 `Q.` 질문 줄은 로톡 **소제목**, `##` 소제목은 **대제목**으로 들어갑니다.

### 원고 다시 쓰기
- 생성 직후 검사에 걸린 원고는 **그 편만 자동으로** 다시 씁니다 (AI 원고 생성 창 옵션).

### 예약 실행 (밤에 자동으로)
AI 원고 생성 창 → **⏰ 예약** → 시작 시간(예: 02:00)과 대상 선택
- **그 시간에 안 쓴 사례 위에서 N건**: 예약 시각에 자동으로 골라서 씁니다 (지금 화면의 시트·분류 기준)
- **지금 체크해 둔 사례 / 입력한 내용**
- 지금 화면의 프로젝트·계정·OneNote 설정 그대로 확인 창 없이 실행합니다.
- **매크로를 켜 둔 채로** 두세요. 예약부터 작업이 끝날 때까지 PC가 절전 모드로 들어가지 않게 합니다 (화면은 꺼져도 됨).
- OneNote 연결이 끊겨 있으면 다시 연결을 시도하고, 안 되면 원고만 파일로 저장합니다.
- 예약을 취소하려면 ⏰ 예약 → **예약 취소**.

기존 붙여넣기 → F5 파싱 → 내보내기 기능은 그대로입니다.
- 원고는 **아래 큰 칸**에 붙여넣으세요. 접두어·키워드 칸에 원고 같은 긴 글(여러 줄)이 들어가면 자동으로 취소하고 알려 줍니다. 예전에 잘못 저장된 접두어·키워드도 불러올 때 자동으로 비웁니다.

## 계정 2개

계정마다 **장기 토큰(약 1년 유지)**으로 연결합니다. 계정끼리 로그인 정보가 완전히 따로라서 한쪽을 연결해도 다른 쪽이 로그아웃되지 않습니다.

**연결 방법 (계정마다 한 번)**
1. AI 원고 생성 창 → 계정 줄의 **[연결]**
2. **[토큰 발급 창 열기]** → 검은 창이 뜨고 브라우저가 열림 → **그 계정으로 로그인 → 승인**
   - 브라우저가 다른 계정으로 로그인돼 있으면, 검은 창에 나온 주소를 복사해 **시크릿 창**에 붙여넣고 로그인하세요.
3. 검은 창에 나온 `sk-ant-oat…` 토큰을 드래그해서 복사 → **[붙여넣기] → [저장하고 확인]** → `✅ 연결 확인됨`

- 계정 줄에 `● 토큰 연결됨 · 5시간 42% · 7일 20%`처럼 보이면 끝입니다.
- 토큰은 exe 옆 `config.json`에 저장됩니다. **config.json은 다른 사람에게 주지 마세요** (그 계정으로 글을 쓸 수 있는 열쇠입니다).
- 약 1년 뒤 만료되면 같은 방법으로 다시 연결하면 됩니다. 연결을 끊으려면 [연결] → **연결 해제**.
- 토큰 없이 예전 방식(Claude Code 로그인)으로 돼 있던 계정도 그대로 쓸 수 있지만, 두 계정을 같이 쓰면 하나가 자꾸 풀릴 수 있어 토큰 연결을 권합니다.
- **1 + 2 동시**: 체크한 사례를 두 계정이 하나씩 가져가며 동시에 작성합니다. OneNote 넣기는 겹치지 않게 순서대로 합니다.

## 지침 관리 (매크로 안에서 추가·삭제·수정)

AI 원고 생성 창 → 프로젝트 칸 오른쪽 **✎ 지침 관리**. 왼쪽에 **모든 지침이 이름으로** 나오고, 그 아래에 들어 있는 파일(메인 지침·참고 파일)과 자동 검사 규칙이 보입니다.

| 하고 싶은 것 | 방법 |
|---|---|
| 새 지침 만들기 | **[+ 새 지침]** → 이름 입력 → 지침 내용 복사(Ctrl+C) → **[복사해 둔 내용으로 전체 바꾸기]** |
| 지침을 새 버전으로 바꾸기 | 그 지침의 `메인 지침` 선택 → 새 내용 복사 → **[복사해 둔 내용으로 전체 바꾸기]** |
| 일부만 고치기 | 편집기에서 바로 고치기 (다른 항목으로 넘어가거나 창을 닫으면 자동 저장) |
| 세부지침 등 참고 파일 추가 | **[가져오기]**(.md/.txt) 또는 **[+ 파일]** 후 붙여넣기 |
| 지침 이름 바꾸기 | 지침 이름(■) 선택 → 이름 고치고 **[이름 바꾸기]** |
| 지침·파일 삭제 | 항목 선택 → **[삭제]** (지침 이름을 고르면 지침 전체 삭제) |

- 바꾼 내용은 **다음 생성부터 바로** 적용됩니다.
- 한 지침 안의 파일은 모두 함께 Claude에게 전달됩니다 (메인 지침 + 참고 파일).

### 자동 검사 규칙이란?
원고를 다 쓴 뒤 **매크로가 지침 위반을 기계적으로 점검**하는 기준입니다 (제목 글자 수, 꼭 1번 나와야 하는 문구, 금지 문구, 본문 최소 글자). 걸린 원고는 그 편만 자동으로 다시 씁니다.
- **지침마다 따로** 저장됩니다. 비워 두면 검사하지 않습니다.
- 직접 만들 필요 없이 **[✨ 지침에서 자동으로 만들기]**를 누르면 Claude가 지침을 읽고 채워 줍니다 (1분 정도, 사용량 조금). 지침을 바꾸거나 파일을 가져오면 "규칙도 새로 만들까요?"를 물어봅니다.
- 본문 길이는 기준보다 15% 넘게 짧을 때만 다시 씁니다 (조금 모자라면 경고만 → 사용량 절약). 기준 글자 수가 있으면 Claude에게 목표 분량을 자동으로 알려 줍니다.

니케 로톡 프로젝트는 **V6 지침**과 V6에 맞춘 검사 규칙이 들어 있습니다:
꼭 1번 = `재범위험성 자료`, `법률사무소 니케의` / 금지 = `로톡/`, `CASE_ID`, `결과1`, `결과2`, `[BLUE]`, `판례` 외 V6 금지 표현 / 제목 최대 35자(결과 괄호 제외) / 본문 최소 1,500자.
V6 세부지침 `nike_lotalk_success_case_v6_detail.md`도 함께 들어 있습니다. 광고 금지 표현(`1위`, `최고`, `최상`, `유일`, `단 1명뿐`, `2배 이상` 등), `반의사불벌죄`, 내부 메타 표현(`사용자가 제공한`, `입력값`, `프로젝트 소스` 등)도 금지 문구로 검사합니다.

### 설정.json

대부분의 값은 AI 원고 생성 창에서 바꾸면 자동으로 저장되므로 직접 고칠 일은 거의 없습니다. 아래는 참고용입니다.

| 키 | 예 | 설명 |
|---|---|---|
| `편수` | `10` | 사례 1건당 원고 수 (자동 검사에 사용) |
| `접두어` | `"로톡"` | OneNote 페이지 제목 앞에 붙는 말 (자리표시 사용 가능) |
| `상단키워드` | `"사건번호 : {사건번호}"` | 본문 맨 위에 굵게 넣을 문구 (자리표시 사용 가능) |
| `하단프리셋` | `["니케성범죄"]` | 하단 링크 프리셋 이름 (화면 아래 체크박스 이름과 같게) |
| `엑셀사용` | `true` | `false`면 직접 입력 모드로 시작 |
| `입력안내` | | 직접 입력 칸 위에 보이는 안내 문구 |
| `모델` | `"opus"` | 비우면 설정의 모델. 프로젝트마다 다르게 지정 가능 |
| `웹검색` | `false` | `true`면 작성 중 웹 검색 허용 (사용량 늘어남) |
| `검사.원고당_정확히1회` | `["재범위험성 자료", "[BLUE]"]` | 원고마다 정확히 한 번 나와야 하는 문구 |
| `검사.금지문구` | `["로톡/", "결과1"]` | 나오면 안 되는 문구 |
| `검사.사건번호_노출금지` | `true` | 엑셀 사건번호가 원고에 나오면 경고 |
| `검사.제목_최대글자` | `35` | 끝의 결과 괄호(와 앞 공백)를 뺀 제목 글자 수 상한, 0이면 검사 안 함 |
| `검사.본문_최소글자` | `1500` | 제목·소제목·표·목록·해시태그·기호·공백을 뺀 서술문 글자 수 하한, 0이면 검사 안 함 |

검사에 걸린 원고는 그 편만 자동으로 다시 씁니다 (AI 원고 생성 창 옵션으로 끌 수 있음).

## claude.ai 프로젝트와 똑같이 뽑으려면

매크로는 claude.ai 프로젝트와 같은 구조로 보냅니다.
**지침 + 소스 파일 = 시스템 프롬프트**(Claude Code 기본 코딩용 프롬프트는 빼고 교체), **사건자료 = 메시지**.
대화가 쌓이지 않고 건마다 새로 시작하므로, 프로젝트에서 새 채팅을 열어 붙여넣는 것과 같습니다.

결과를 맞추려면 아래 4가지를 claude.ai 프로젝트와 똑같이 맞추세요.

| claude.ai 프로젝트 | 매크로에서 맞출 곳 |
|---|---|
| 프로젝트 지침 | `지침.md`에 그대로 붙여넣기 |
| 프로젝트 지식(소스 파일) | 같은 폴더에 .md/.txt로 넣기 (**PDF·워드는 텍스트로 변환해서** 넣기) |
| 채팅창 모델 선택 (Opus/Sonnet) | `설정.json`의 `모델` |
| 웹 검색 켜짐 여부 | `설정.json`의 `웹검색` |
| 설정 → 개인 선호(Preferences)에 적어둔 내용 | 원고에 영향을 주는 내용이면 `지침.md` 끝에 추가 |

같은 사례 하나를 프로젝트와 매크로에서 각각 뽑아 비교해 보고 위 값을 조정하는 것을 권합니다.

## 접두어·키워드 자리표시

접두어와 키워드 칸(메인 화면, AI 생성 창, `설정.json` 모두)에 아래 표시를 쓰면 **글마다 자동으로 채워집니다.**

| 표시 | 들어가는 값 | 예 |
|---|---|---|
| `{사건번호}` | 엑셀 사건번호 (직접 입력이면 사건자료에서 `2021형제55` 같은 형태를 찾아서) | 2021형제55 |
| `{날짜}` | 내보내는 날짜 | 11/24 |
| `{범죄명}` | 엑셀 범죄명 | 군인등강제추행 |
| `{결과1}` / `{결과2}` | 엑셀 결과 / 결과2 | 불기소 / 기소유예 |

니케 로톡 프로젝트 기본값:
- 접두어 `로톡` → 제목 `로톡 [군인등강제추행변호사 성공사례] …`
- 키워드 `사건번호 : {사건번호}` → 본문 맨 위 굵게 `사건번호 : 2021형제55`

값을 찾을 수 없으면(예: 붙여넣기로 가져온 글에는 사건번호 정보가 없음) 그 줄은 넣지 않습니다.
사건 1건에서 나온 원고 10편에는 모두 같은 사건번호가 들어갑니다.

## 사용량 절약

사용량의 대부분은 **원고를 쓰는 출력 + 쓰기 전에 생각하는 양**입니다 (지침 입력은 약 7천 토큰으로 작은 편).
같은 사례 1건(원고 10편)을 생각 깊이별로 실제로 뽑아 비교한 결과:

| effort | 출력 토큰(생각 포함) | 걸린 시간 | 원고 분량 | 지침 검사 |
|---|---|---|---|---|
| 기본값(지정 안 함) | 34,879 | 5분 9초 | 15,429자 | 통과 (제목 1개 60자 초과) |
| **medium (기본 설정)** | **28,525 (−18%)** | **4분 7초** | **15,774자** | **통과** |
| low | 14,120 (−60%) | 2분 4초 | 12,734자 (−17%) | 통과, 글이 조금 짧고 구성이 단순해짐 |

- 매크로는 항상 **medium(기본 모드)**으로 씁니다. 품질은 그대로 두고 생각 낭비만 줄인 설정입니다.
- 매크로가 자동으로 하는 절약: Claude Code 기본 프롬프트 제거(고정 입력 약 2,970 → 1,370토큰), 도구·MCP 끔, 대화 기록 없음, 이미 쓴 사례 제외, 실패 시 써진 부분 저장.
- 지침 파일 자체를 줄이는 것도 도움이 됩니다. 같은 규칙을 두 번 쓰지 않기 (예: 마지막 '하드 게이트'가 앞 내용을 반복하면 짧게).

## 엑셀 사례

- 머리글에 `사건번호`, `요약`이 있는 시트를 모두 읽습니다. 열 순서가 시트마다 달라도 됩니다.
- AI에 보내는 칸: 사건번호(원고에는 노출 금지), 범죄명, 결과, 결과2, 요약, 처분이유(또는 불리한점/유리한점)
- **보내지 않는 칸: 이름(실명), 범죄명 분류, 사용체크, 비고, 순**
- 요약이 비었거나 `(내용없음)`인 행은 목록에서 빠집니다.
- 이미 쓴 사례: `사용기록.csv`(프로젝트별, 자동 기록) + 엑셀 `사용체크` 열 표시(설정에서 끌 수 있음)
- **원본 엑셀은 읽기만 하고 수정하지 않습니다.** 실명이 들어 있으므로 git에 올리지 마세요 (.gitignore 처리됨).

## 설정

| 항목 | 설명 |
|---|---|
| Claude 모델 | 비우면 Claude Code 기본값. `sonnet` / `opus` 지정 가능 (opus는 사용량을 더 씀) |
| 실행 파일 경로 | 보통 비워두면 자동으로 찾음 |
| 최대 대기 시간 | 사례 1건(10편) 기준, 기본 30분 |

- 사례 1건에 긴 원고 10편이라 사용량을 꽤 씁니다. 한 번에 1~3건씩 돌리는 걸 권합니다.
- 사용량 한도에 걸리면 로그에 안내가 나오고 남은 건은 멈춥니다.
